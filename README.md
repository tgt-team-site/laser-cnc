# Laser CNC: Interactive 3D Website

Interactive 3D website for our Laser CNC cutting and engraving machine.
Damanhour University, Faculty of Engineering.

Team: Ahmed Galal, Yousef Ibrahem, Mustafa Mahmoud.

## Run locally
Open `index.html` in any modern browser (internet needed for Three.js and fonts).

## Host on GitHub Pages
1. Upload `index.html` (and this README) to a public repository.
2. Settings, then Pages, then Deploy from a branch, then `main` and `/ (root)`, then Save.
3. Your site: `https://YOUR-USERNAME.github.io/REPO-NAME/`
